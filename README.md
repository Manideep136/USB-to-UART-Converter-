# USB-to-UART-Converter

A compact USB-to-UART converter PCB designed for communication between a computer and microcontroller-based systems such as STM32, ESP32, Arduino, and other embedded development boards.

Features
USB interface for connection to a PC or laptop
UART serial communication interface
TX and RX signal breakout
Compact PCB design
Designed using KiCad
Suitable for programming, debugging, and serial communication
Easy connection to 3.3 V / 5 V UART-based systems
Applications

This USB-to-UART converter can be used for:

STM32 development and debugging
ESP32 serial communication
Arduino development
Embedded-system debugging
Serial terminal communication
Firmware programming
UART-based sensor/module communication
Interface
USB Side

The USB interface provides:

USB 5 V power
USB D+
USB D−
GND


PCB Design

The PCB was designed using KiCad, including:

Schematic design
Component selection
PCB layout
Routing
Design Rule Check (DRC)
Gerber generation
